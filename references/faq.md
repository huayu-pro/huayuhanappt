# FAQ：常见踩坑库

按「安装 / 配置 / 生成 / 配图 / 排版 / 图表」分组。每条都是真实会出现的问题。

## 安装

**Q: `pip install` 很慢或超时？**
换国内镜像：
```bash
pip install python-pptx requests Pillow -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**Q: 提示缺少 python-pptx 就直接退出了？**
脚本在导入阶段就会检查三个依赖。按提示装齐再跑：
```bash
pip install python-pptx requests Pillow
```

**Q: Python 版本有要求吗？**
3.8 及以上。用 `python3 --version` 查看。部分系统上命令是 `python3` 而不是 `python`。

**Q: Pillow 没装能用吗？**
能，但会跳过图片完整性校验——下载到损坏图片时无法识别，可能在 PPT 里显示为裂图。建议装上。

## 配置

**Q: 我按文档复制了 .env，为什么还是不生效？**
v1.0.1 从来没写过加载 .env 的代码，这是那个版本的真实缺陷。v2.0.0 启动时会自动读取包目录下的 `.env`。如果仍不生效，检查文件是否真的叫 `.env`（不是 `.env.txt`）。

**Q: 密钥填在哪里？网页还是文件？**
两种都行，效果相同。网页面板在 `python start_ui.py` 后打开的那个页面里；文件就是包目录下的 `.env`，`变量名=值` 一行一个。

**Q: 环境变量和 .env 冲突了听谁的？**
环境变量优先。

**Q: 怎么确认密钥配好了？**
网页界面的配置卡片会显示每个来源是「已配置」还是「未配置」。命令行下没有专门命令，但配好的来源会出现在爬图阶段的「可用来源」列表里。

**Q: .env 会被打包分享出去吗？**
不会——`.env` 不在交付文件清单里。但如果你自己压缩整个目录发送，注意别带上它。

## 生成

**Q: 生成卡住不动？**
九成是配图阶段在等网络。两种处理：
1. 等——六级来源逐个超时（每个 15 秒），页数多时累计时间不短
2. 打断后加 `--skip-images` 先出排版

**Q: 中途按了 Ctrl+C，输出目录里有残留文件？**
会留下半成品 pptx 和部分图片。重跑即可，pptx 会被覆盖，旧图片若页码/关键词不匹配则残留（用 `--clean` 清掉）。

**Q: 同样的输入，两次生成结果一样吗？**
版式一定一样。配图可能不同——图库返回结果会变。想完全可复现就加 `--skip-images`。

**Q: 输出目录里找不到文件？**
`--output` 是相对路径时，相对于你运行命令时的目录。用绝对路径最稳：
```bash
python huayu_hanako_ppt.py --content 汇报.json --output ~/桌面/PPT输出
```

**Q: 文件名带斜杠或特殊字符？**
v1.0.1 会在 30 页全部渲染完后才崩。v2.0.0 启动时就清理非法字符，并打印改成了什么。

**Q: 页数怎么控制？**
用 `--example` 的样例是固定页数；自己写内容文件时增删 `slides` 项；网页界面直接拖「目标页数」。范围 8–40，推荐 25–30。

## 配图

**Q: 一张图都没下来？**
看生成结束后的失败汇总。全部失败通常是网络不通（Bing 也打不开）。只部分失败，换更具体的关键词——`digital government` 比 `government` 命中率高。

**Q: 关键词写中文还是英文？**
英文通常命中率更高（Pexels/Unsplash/Pixabay 的图库以英文标注为主）。中文主题词在百度来源上有优势，所以两个都排进去了。

**Q: 下载的图是裂图/花屏？**
装了 Pillow 时会自动校验并重试，三次都不过就放弃该图。没装 Pillow 则只检查文件大小——装上能避免这类问题。

**Q: 图片把正文挡住了？**
v2.0.0 的正文页配图固定在右下角，尺寸收敛过。若你的要点特别长，减少该页 `bullet_points` 条数，或去掉该页的 `image_keywords`。

**Q: 封面/章节页的配图太抢眼？**
这两类页的配图都加了半透明遮罩（封面透明度 25%、章节页透明度 45%，即不透明度 75%/55%）。想彻底不要，把对应页的 `image_keywords` 删掉。

**Q: 配图版权有问题吗？**
公网图库授权各不相同。公开发布前自行核实，详见 [image-providers.md](image-providers.md) 的版权提示。

## 排版

**Q: 文字溢出版面/被裁切？**
单页要点超过 8 条就容易溢出。拆成两页，或把长句改短。文本框不会自动缩字号——这是为了保证版式一致。

**Q: 主题色圆点是黑的？**
v1.0.1 的 bug：项目符号颜色被写进了非法的 XML 位置，PowerPoint 直接忽略。v2.0.0 已修复（`buClr` 必须是 `pPr` 的直接子元素且排在 `buChar` 之前）。

**Q: 想加自己的主题色？**
编辑 `ppt_skill/config.py` 里的 `MORANDI_PALETTES`，照现有格式加一组八个颜色键（primary/secondary/accent/bg/text/title/light/lighter），再在 `CHART_COLORS` 里配一组图表色。

**Q: 能改字体吗？**
默认中文走系统默认字体、西文 Arial。代码块固定 Consolas。想全局替换，改 `ppt_skill/rendering/base.py` 里 `add_textbox` 的 `font_name` 参数默认值。

**Q: 引用块只有一行字但底色很高？**
引用块高度按「每行可容纳字数 × 估算行数」算，短文本会有余量。想紧凑就缩短 `quote_text`。

## 图表

**Q: 表格数据没变成图表？**
三个必要条件：`slide_type` 是 `content` 或 `data`、有 `table_data`、`chart_type` 填了值或能自动推断。另外，数值列必须**整列都能解析成数字**——有一个单元格是「暂无」这类文字，整列放弃。

**Q: 饼图少了一列数据？**
饼图只接受一个数值系列。传了多个时保留第一个，并打印警告说明忽略了哪些列。想看多列对比，改用 `bar`。

**Q: `1200亿` 怎么变成 1.2e11 了？**
`亿` 按 10⁸ 换算，`万` 按 10⁴。这是 v2.0.0 修正的行为——v1.0.1 会把「亿」当干扰字符删掉，得到错误的 1200。

**Q: 图表区域一片空白？**
先看有没有警告「图表生成失败，改用表格展示」。若连表格也没有，检查 `table_data.rows` 是否为空，或整列都不是数值（有一个单元格写「暂无」这类文字，整列就会放弃）。

**Q: 想让图表用别的颜色？**
图表色跟随主题。在 `ppt_skill/config.py` 的 `CHART_COLORS` 里改对应主题的那组十六进制值。

## 其他

**Q: 能把 Markdown/Word 直接转成 PPT 吗？**
不直接支持。把正文粘到网页界面，或整理成 JSON 内容文件。大纲拆分只认章节标记和段落结构。

**Q: 支持英文 PPT 吗？**
支持。界面和注释是中文的，但内容、标题、要点可以是任意语言——版式按文字宽度自适应。

**Q: 想批量生成多份？**
写个 shell 循环调命令行：
```bash
for f in 内容/*.json; do
  python huayu_hanako_ppt.py --content "$f" --skip-images
done
```

**Q: 出错了怎么反馈？**
带上完整报错文字和退出码（`echo $?` 的输出）。如果方便，附上内容文件片段。
